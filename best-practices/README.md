# The controlled vocabulary guide

This folder holds one guide. It covers the language work that comes before an ontology.

| File | What it holds |
|---|---|
| [controlled-vocabulary.md](controlled-vocabulary.md) | The guide: how to hunt the words, split them into meanings, and record a preferred label, a scope note, a stable ID, the aliases and the map of local keys for each. Its example is made up. |
| [controlled-vocabulary.html](controlled-vocabulary.html) | The same guide as a page for a browser |
| [controlled-vocabulary-end-to-end.png](controlled-vocabulary-end-to-end.png) | A diagram of the method's four steps |

The guide stops at the vocabulary. For the ontology itself, the method is the `ontology` skill in `skills/ontology/`.
